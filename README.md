# OCL Server Prepare

Интерактивный установщик для первоначальной настройки сервера на Ubuntu 24.04 LTS.

Проект развивается небольшими шагами. Текущая версия проверяет запуск от root и
поддерживаемую ОС, затем предлагает сменить пароль root, создаёт пользователя и
выдаёт ему права sudo.
Остальные шаги настройки и обновление пока не реализованы.

## Установка и обновление одной командой

Подключитесь к серверу под root. Если используете пользователя с правами sudo,
сначала выполните:

```bash
sudo -i
```

Для загрузки нужны `curl` и `tar`. Единая команда запуска установщика:

```bash
ocl_installer=$(curl -fsSL https://raw.githubusercontent.com/lenyldes/OCL-Server-Prepare/main/install.sh) && bash -c "$ocl_installer"
```

Команда полностью загружает скрипт и запускает его через Bash только при успешной
загрузке. Скрипт скачивает архив проекта и запускает все доступные шаги настройки.
Ввод с терминала остаётся доступен для вопросов установщика. Временные файлы
удаляются после завершения.

Команда станет доступна после публикации изменений в ветке `main` на GitHub.

## Смена пароля root

На вопрос `Сменить пароль root? [y/N]` введите `y` для смены пароля или нажмите
Enter для пропуска. При повторном запуске установщик снова задаёт этот вопрос.

Для генерации используется системная команда `openssl`. Установщик создаёт
случайный пароль длиной 30 символов и выводит его после успешной смены. Сохраните
пароль: установщик не записывает его в открытом виде в файлы или логи.

## Создание пользователя

Введите имя пользователя или нажмите Enter для выбора `lenyldes`. Установщик
запускает интерактивный `adduser`, который создаёт домашний каталог и группу
пользователя и запрашивает пароль с повторным вводом. Вопросы про полное имя,
кабинет и телефоны пропускаются. Пароль не попадает в переменные установщика.

Если пользователь уже существует, его пароль сохраняется. Если пароль не задан
или заблокирован, установщик остановится с подсказкой выполнить `passwd` для
этого пользователя и повторить запуск.

## Права sudo

После создания или проверки пользователя установщик автоматически добавляет его
в группу `sudo`, сохраняя членство в остальных группах. Повторный запуск безопасен.
Для применения новых прав пользователю нужно выйти из системы и войти заново.
Настройка sudo без пароля пока не реализована.

## Локальный запуск

Из каталога проекта на сервере:

```bash
bash setup.sh
```

## Структура проекта

```text
install.sh               # Загрузка проекта и запуск настройки
setup.sh                 # Проверки и порядок выполнения шагов
steps/root-password.sh   # Смена пароля root
steps/user.sh            # Создание пользователя
steps/sudo.sh            # Выдача прав sudo
```
